# Todo-list
This app is for developers. Imagine you have some bugs in your project or want to optimize it, but don't have time and want to do it later. You can enter your project's name and then add tasks to it, so you know in which project they should be fixed. I break it into several (5) files. The mid_frame.py and database.py are written by DeepSeek
How to use it: 
1: Add the project's title in the entry at the bottom of the app. Make sure you are entering a valid name.
2: Click on the projects you want, then start to add whatever you want to them. For example. Todo list> Optimize database
3: You can easily delete the Project or task you want by clicking on the red button.

Note: the UI/UX, main.py, top_frame.py, and bottom_frame.py were developed and written by me, but as I mentioned, the mid_frame.py and database.py were completed and developed by DeepSeek.
